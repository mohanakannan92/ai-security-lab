This system uses a layered AI defense architecture:

Layer 1 – Input Defense:
Detects malicious patterns, intent, and sequential attack behavior.

Layer 2 – Decision Intelligence:
Calculates risk and confidence, then decides allow, guard, or block using adaptive thresholds.

Layer 3 – Output Protection:
Sanitizes model responses to prevent leakage of internal or sensitive information.

Layer 4 – Learning & Adaptation:
Continuously improves using feedback loops and dynamic pattern learning.
