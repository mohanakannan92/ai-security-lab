🛡️ Built an AI Security Red Team Lab from scratch

Over the past few days, I worked on a hands-on project to understand **how AI systems can be attacked — and more importantly, how to defend them.**

Instead of just learning theory, I built a complete **AI security testing platform**.

🔍 What it does:

• Simulates real-world attacks like
– Prompt Injection
– Role Override
– Instruction Bypass
– Data Extraction
– Multi-step attacks

• Evaluates model responses as:
✅ Blocked
⚠️ Bypass
❌ Leak

• Identifies weak areas using an analysis engine

• Visualizes everything in a **live Streamlit dashboard** with:
📊 Metrics (Block / Bypass / Leak rates)
📉 Category-wise weaknesses
📈 Security score trends over time
📋 Detailed test results
📥 Exportable reports

---

💡 Key Insight:

Even when there are **zero leaks**, systems can still be vulnerable due to **bypass attacks**.

This project helped me understand:

👉 Strong output filtering ≠ strong security
👉 Input validation and intent detection are critical

---

🚀 Tech Stack:

Python | FastAPI | Streamlit | Pandas | Matplotlib

---

📊 Example Result:

• 80% attacks blocked
• 20% bypass detected
• 0% data leakage
